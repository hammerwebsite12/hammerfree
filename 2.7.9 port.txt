0. WHY THIS PORT EXISTS (REGISTRAR / DOMAIN)
================================================================================

Anker (Server 2) moved to interim host **https://ankergames.to/** (Discord announcement).
Legacy **ankergames.net** DNS/registrar was down for many users in late Sep 2026.

Windows 2.7.9 fixes:
  - Catalog + CSRF + gate URLs use **ankergames.to** first
  - **ankergames.net** kept as fallback when DNS returns
  - Cloudflare Workers: ANKER_BASE_URL=https://ankergames.to (already deployed)
  - client_resolve gate path when Worker cannot CSRF from datacenter IP

Android (gamehub) and SteamOS (playzipdl) trees reviewed 2026-09-29 still hardcode
**ankergames.net** → Server 2 browse/download/gate **broken** until ported.

Server 3 (Astral): Windows code exists but UI hidden (SERVER3_UI_ENABLED=False).
**Do not** add Server 3 to Android/SteamOS in this port unless product owner asks.

4. ANDROID — RECOMMENDED IMPLEMENTATION (AGENTS)
================================================================================

### 4.1 Single source of Anker hosts (mirror Windows base_urls.py)

Add: quickplay/.../core/AnkerHosts.kt (or store/AnkerHosts.kt)

  - const val PRIMARY_BASE = "https://ankergames.to"
  - const val LEGACY_BASE = "https://ankergames.net"
  - val STORE_HOSTS = setOf("ankergames.to", "www.ankergames.to",
                            "ankergames.net", "www.ankergames.net")
  - fun isStoreHost(host: String): Boolean
  - fun activeBaseUrl(): String  — optional: probe GET /games for "uiPostCard" like Windows
    (use OkHttp + desktop UA; try PRIMARY then LEGACY; cache result in memory)

Update Constants.kt:

  const val ANKER_BASE = AnkerHosts.PRIMARY_BASE   // or activeBaseUrl() if probing

### 4.2 GateUrls.kt

Replace hardcoded host checks with AnkerHosts.isStoreHost(host) for gate/download-file
hops. isCdnUrl: return false when isStoreHost(host) (same as Windows — store host is
never final CDN).

### 4.3 GateWebViewHelper.kt

firstPartyOrigins = setOf(
  "https://ankergames.to", "https://www.ankergames.to",
  "https://ankergames.net", "https://www.ankergames.net",
)

### 4.4 GateAdBlock.kt

Add "ankergames.to", "www.ankergames.to" to allowlist (keep .net for fallback).

### 4.5 MainActivity.kt

Sync cookies for both registrable domains (or parse host from Constants.ANKER_BASE):

  HttpClients.syncCookiesToWebView("ankergames.to")
  HttpClients.syncCookiesToWebView("ankergames.net")  // optional fallback

### 4.6 Optional: 502 client_resolve parity

Windows falls back to local gate on 502 csrf_failed from Worker. Android AnkerClient
currently throws on non-200. Consider:

  if (resp.code == 502 && data?.optString("error") in csrfErrors)
      return resolveViaClientGate(slug, label)

Match error set: csrf_failed, csrf_expired, csrf_empty, gate_turnstile_required

### 4.7 Version bump

Bump gamenative (or root) versionName / versionCode to **2.7.9** (or next Android ship).
Update any in-app "QuickPlay x.y.z" string.

### 4.8 Verification (Android)

  [ ] Settings → Server 2 → Browse shows games (uiPostCard cards)
  [ ] Search returns results
  [ ] Licensed device: download starts (Worker resolve or client_resolve + gate)
  [ ] Gate WebView loads ankergames.to/download/... (not rejected as non-gate)
  [ ] CDN URL captured (dlproxy / datanodes / archive extension)
  [ ] Phone on mobile data + WiFi

### 4.9 Do NOT break

  - Desktop Chrome User-Agent on catalog requests (403 if plain okhttp UA)
  - Gate adblock must not break challenges.cloudflare.com
  - StoreJunkCleaner: do not delete folders with real game content (Metaphor lesson)
